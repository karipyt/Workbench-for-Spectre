Central project brief

Project Brief

A Design/Validation Project on an existing design, aiming to improve the engine using Ansys simulation tools and add electronic assistance.

Physical modelling is limited to a 3D printed model, prioritising a coherent concept and credible evidence over full-engine fidelity.

✓ Minimum Outcomes

  • Requirements-led propulsion concept with an agreed operating envelope.
  • Controlled parametric CAD assembly plus analysis-ready geometry releases.
  • Internally consistent cycle/system model providing shared boundary conditions.
  • Verified and validated CFD, thermal/structural, and transient-dynamics work packages.
  • Controls/electronics concept and cold actuated printed demonstrator.

✕ Explicit Exclusions

  • Complete core design
  • Manufacture/operation of a hot engine
  • Certification
  • Proprietary engine-map recreation
  • Full 3D CFD across the envelope
  • Detailed combustion chemistry
  • Advanced blade cooling/life
  • Two-way FSI
